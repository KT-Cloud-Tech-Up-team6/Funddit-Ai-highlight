# 쇼츠 자막 디자인 스펙

FE 시안(Figma) 기준. 쇼츠는 세로 9:16으로 렌더링되며 자막은 영상에 구워진다.

---

## 1. 자막 2종

| 구분 | 대상 | 화면 위치 | 목적 |
| --- | --- | --- | --- |
| **발화 자막** (Speech) | **모든 발화** | 상단 | 진행자가 말하는 내용을 따라감 |
| **강조 자막** (Point) | **핵심 발화만** | 중앙 하단 | 눈이 가장 먼저 가는 자리 — 수치·혜택 강조 |

두 자막은 **동시에 표시된다.** 겹치지 않도록 세로 위치를 분리한다.

---

## 2. 시안 스펙 (390px 기준)

두 자막의 텍스트 박스 규격은 동일하다. **세로 위치만 다르다.**

| 항목 | 값 |
| --- | --- |
| x 좌표 | 74 |
| 중앙 정렬 | 가로 가운데 |
| max lines | 3 |
| 폰트 | Pretendard 14pt Medium |
| line height | 142% |
| text box | w 242 × h 60 |
| 배경 | `#000000` opacity 80% |

### 세로 위치

| 자막 | 시안 y | 화면상 위치 |
| --- | --- | --- |
| 발화 자막 | 194 | 상단 (플레이어 헤더 아래) |
| 강조 자막 | — | 중앙 하단 (액션 버튼 왼쪽) |

> 시안에 두 블록 모두 `y:194`로 적혀 있으나, 실제 배치는 상단/중앙하단으로 분리되어 있다.
> **강조 자막의 정확한 y 좌표는 Figma 재확인이 필요하다.** 아래 구현값은 기존 렌더링 기준이다.

---

## 3. 렌더링 환산 (1080 × 1920)

시안 390px → 렌더링 1080px, **배율 2.769×**

| 항목 | 시안 (390px) | 렌더링 (1080px) |
| --- | --- | --- |
| x 좌표 | 74 | **205** |
| text box 폭 | 242 | **670** |
| text box 높이 | 60 | **166** |
| 폰트 크기 | 14pt | **39px** |
| 좌우 여백 (MarginL/R) | 74 | **205** |

---

## 4. ASS 스타일 적용값

`poc/render.py` 의 스타일 정의에 반영한다.

### 발화 자막 (Speech)

```
Style: Speech, {font}, 39, {white}, {white}, {ink}, &HCC000000,
       0,0,0,0, 100,100, 0,0,
       3,        ← BorderStyle 3 = 불투명 배경 박스
       7,0,      ← Outline 7 (배경 패딩), Shadow 0
       8,        ← Alignment 8 = 상단 중앙
       205,205,  ← MarginL, MarginR
       {speech_mv}, 1
```

| 항목 | 값 | 근거 |
| --- | --- | --- |
| Fontsize | 39 | 14pt × 2.769 |
| BackColour | `&HCC000000` | 검정 80% (ASS는 alpha 반전 — `0xCC` = 80% 불투명) |
| BorderStyle | 3 | 배경 박스 |
| Alignment | 8 | 상단 중앙 |
| MarginL/R | 205 | x74 × 2.769 |
| MarginV | 537 | y194 × 2.769 |

### 강조 자막 (Point / Spec / Benefit / Result)

```
Style: Point, {font}, 80, {white}, {white}, {ink}, {shadow},
       -1,0,0,0, 100,100, 2,0,
       1,        ← BorderStyle 1 = 외곽선
       6,3,      ← Outline 6, Shadow 3
       2,        ← Alignment 2 = 하단 중앙
       60,60, {point_mv}, 1
```

| 항목 | 값 | 비고 |
| --- | --- | --- |
| Fontsize | 80 | 강조용 — 발화 자막의 2배 |
| Bold | -1 (켬) | |
| BorderStyle | 1 | 배경 박스 없이 외곽선 + 그림자 |
| Alignment | 2 | 하단 중앙 |

강조 자막은 배경 박스 대신 **외곽선 + 그림자**를 쓴다. 영상 위에서 글자만 떠 보이게 하는 편이 시선을 끈다.

## 5. 상단 제목 (Title)

쇼츠 상단에 구간 전체(0초 ~ 끝)에 걸쳐 고정 표시된다.

### 형식

```
[상품명] AI가 정한 제목
```

실제 예시:

```
[로보락 F25] 고추기름도 한 번에
[로보락 F25] 머리카락 엉킴 제로
[로보락 F25] 90도 온수 세척
```

### 조립 규칙

**상품명은 코드가 붙인다.** 모델에게는 구간 요약만 맡긴다 —
모델이 상품명을 지어내면 틀린 이름이 영상에 그대로 박히기 때문이다.

| 모델 출력 | 최종 제목 | 처리 |
| --- | --- | --- |
| `고추기름도 한 번에` | `[로보락 F25] 고추기름도 한 번에` | 정상 |
| `로보락 F25 머리카락 엉킴 제로` | `[로보락 F25] 머리카락 엉킴 제로` | 상품명 중복 제거 |
| `[로보락 F25] 90도 온수 세척` | `[로보락 F25] 90도 온수 세척` | 대괄호 형태도 중복 제거 |
| 빈 값 / `null` | `[로보락 F25] 시연` | 구간 라벨로 대체 |
| (상품명 미전달) | `고추기름도 한 번에` | 대괄호 없이 제목만 |

상품명은 `terms.product_name` (BE `productName`) 에서 온다.
모델이 만드는 뒷부분은 **최대 14자**다.

구현: `poc/m2_captions.py` `build_title()`

### 스타일

```
Style: Title, {font}, 78, {cream}, {white}, {ink}, {shadow},
       -1,0,0,0, 100,100, 3,0,
       1,        ← BorderStyle 1 = 외곽선
       5,3,      ← Outline 5, Shadow 3
       8,        ← Alignment 8 = 상단 중앙
       60,60, {title_mv}, 1
```

| 항목 | 값 |
| --- | --- |
| Fontsize | 78 |
| 색상 | 크림 `&H00E8F4FF` |
| Bold | -1 (켬) |
| Alignment | 8 (상단 중앙) |
| 표시 구간 | 0초 ~ 영상 끝 (고정) |

제목은 발화 자막(Speech)과 **같은 상단 영역**을 쓴다.
`title_mv`(190) < `speech_mv`(210) 이므로 제목이 위, 발화 자막이 아래에 놓인다.

### 반영 위치

| 위치 | 필드 | 비고 |
| --- | --- | --- |
| 영상 자막 | ASS `Title` 스타일 | 영상에 구워짐 |
| API 응답 | `GET /jobs/{id}/shorts` → `title` | |
| BE 콜백 | `HighlightCallback.title` (`kind=CLIP`) | |
| 수정 API | `PATCH /jobs/{id}/shorts/{cid}/title` | 판매자가 변경 가능 |

**제목 수정 시 영상 자막은 바뀌지 않는다.** 이미 렌더링이 끝났기 때문이다.
업로드에 쓸 메타데이터상의 제목만 바뀐다.

---

## 6. 세로 위치 (MarginV)

레이아웃에 따라 달라진다.

| 항목 | crop (세로 꽉 채움) | letterbox (원본 비율 + 여백) |
| --- | --- | --- |
| 제목 (`title_mv`) | 190 | 230 |
| 강조 자막 (`point_mv`) | 470 | 400 |
| 발화 자막 (`speech_mv`) | 210 | 120 |

`speech_mv`는 **Alignment 8(상단 기준)** 이므로 위에서부터의 거리다.
`point_mv`는 **Alignment 2(하단 기준)** 이므로 아래에서부터의 거리다.

---

## 7. 색상

강조 유형별로 색을 달리해 정보 종류를 구분한다.

| 스타일 | 강조 유형 | 색상 | 값 (ASS BGR) |
| --- | --- | --- | --- |
| `Point` | 일반 강조·스토리 | 흰색 | `&H00FFFFFF` |
| `Spec` | 스펙·기능 | 민트 | `&H00D4F0D0` |
| `Benefit` | 혜택·가격 | 코랄 | `&H00A0A0FF` |
| `Result` | 결과·효과 | 라벤더 | `&H00F0D8C0` |
| — | 외곽선 | 잉크 | `&H00302820` |
| — | 그림자 | 검정 60% | `&H60000000` |

> ASS 색상은 **BGR 순서**다. RGB로 읽으면 색이 뒤집힌다.

강조 구간 안에서 특정 단어만 더 강조할 때는 `HIGHLIGHT_COLOR = &H007090FF&` 를 인라인 태그로 적용한다.

## 8. 폰트

| 순위 | 폰트 | 비고 |
| --- | --- | --- |
| 1 | Han Santteut Dotum | 기본 |
| 2 | Malgun Gothic | 시스템에 1순위가 없을 때 |

시안의 Pretendard는 **FE 화면 UI 기준**이다. 영상에 구워지는 자막은 렌더링 서버에 설치된 폰트를 쓰므로 위 2종을 사용한다.

FE 시안 문서(`BUYER_LIVE_REPLAY.md`)에 따르면 강조 자막은 **Gmarket Sans**(일반 24px Medium / 강조 28px Bold)를 쓴다고 되어 있다. 영상 자막과 FE 오버레이 자막을 어느 쪽으로 통일할지는 협의가 필요하다.

## 9. 확인 필요

| # | 항목 | 내용 |
| --- | --- | --- |
| 1 | 강조 자막 y 좌표 | 시안에 `y:194`로 적혀 있으나 실제 배치는 중앙 하단. Figma 재확인 필요 |
| 2 | 폰트 통일 | 시안 Pretendard/Gmarket Sans ↔ 렌더링 Han Santteut Dotum |
| 3 | 자막 렌더링 주체 | 영상에 굽는 방식(현재) ↔ FE 오버레이 방식 |

3번이 정해져야 1·2번이 의미를 갖는다.
**영상에 구우면** 어디서 재생해도 자막이 보이지만 수정이 불가능하고,
**FE 오버레이면** 수정·다국어가 가능하지만 SNS 업로드 시 자막이 사라진다.

현재는 SNS 업로드가 목적이라 **영상에 굽는 방식**으로 구현되어 있다.
